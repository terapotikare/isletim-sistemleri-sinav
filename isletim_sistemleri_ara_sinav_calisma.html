🔥 Sınavda En Çok Sorulan 8 Klasik Tuzak

  • Kesme bir hata değil, olay bildirimidir.
  • Bekleyen süreç olay bitince doğrudan çalışmaz → önce Hazır olur.
  • Yarış durumu için iki çekirdek şart değil → tek çekirdekte de olur.
  • Yönetici hesabı ≠ Çekirdek modu (uygulama yine kullanıcı modunda!).
  • Mutex ≠ Semafor (veri koruması vs kapasite/koşul sayımı).
  • SJF her zaman en iyi değil (süre bilinmez, uzun iş aç kalır).
  • Zaman dilimi (q) küçüldükçe hep iyileşmez (bağlam değiştirme maliyeti artar).
  • Sayfa hatası program bozuk demek değil → sayfa sadece RAM'de değil, diskten gelir!

1) 6 Haftanın Tek Cümlelik Özü

H1Soyutlama (kolay nesne/dosya adı) + Kaynak Yönetimi (paylaşım: zamanda CPU/yazıcı, alanda RAM). Toplu / Etkileşimli / Gerçek zamanlı (süre sınırı!).
H2Sürücü=yazılım, Denetleyici=donanım. Sistem çağrısı (uygulama ister) vs Kesme (aygıt bildirir, hata değil!). Kullanıcı vs Çekirdek modu (yönetici hesabı ≠ çekirdek modu!). Monolitik (hızlı, hata yayılır) vs Mikroçekirdek (yalıtımlı, mesaj maliyeti).
H3Program (disk) vs Süreç (yürütülen + PID + PCB). Durumlar: Hazır / Çalışan / Bekleyen (Bekleyen → Hazır!). Thread ortak: adres alanı, kod, ortak veri, açık dosyalar; ayrı: PC, yazmaç, yığın, durum. Tek çekirdek = eşzamanlı, çok çekirdek = paralel.
H4Yarış durumu tek çekirdekte de olur! Kritik bölge = oku+kontrol+yaz tamamı! Mutex (atomik kilit, veri korur) vs Semafor (down/up, kapasite/koşul). Üretici-Tüketici: Koşul izni mutexten ÖNCE alınır!
H5T=C−V, R=İlkCPU−V, W=T−B. FCFS (konvoy/uzun iş kısa işi bekletir), SJF (ort. W min ama süre bilinmez + aç kalma), RR (en iyi R, küçük q → s/(q+s) maliyeti artar, büyük q → FCFS).
H6Dosya ≠ RAM (4 MB JPEG → 36/108 MB). Dış parçalanma (otopark) → sayfalama çözer; İç parçalanma (son sayfa) kalır. Sayfa (sanal) ↔ Çerçeve (RAM), 4 KiB=4096 B, ofset değişmez! CPU düşük + RAM %96 + Disk %100 = Takas (RAM artır!). Sayfa hatası olağandır.

2) Formüller & Sayısal Kontroller

Zamanlama (Hafta 5):
• Toplam Kalış: T = C − V
• İlk Yanıt: R = İlk CPU − V
• Bekleme (G/Ç yoksa): W = T − B
• Yönetim Payı: s / (q + s)
• Ders A=8, B=4, C=2: FCFS(R=6,67 W=6,67 T=11,33) • SJF(R=2,67 W=2,67 T=7,33) • RR q=2(R=2 W=5,33 T=10). Hepsinde son bitiş = 14!
Bellek & Adres Çevirme (Hafta 6):
• Sayfa No = ⌊Sanal / Sayfa Boyutu⌋
• Ofset = Sanal mod Sayfa Boyutu (Değişmez!)
• Fiziksel Adres = Çerçeve × Sayfa Boyutu + Ofset
• 1 KiB = 1024 bayt • 4 KiB = 4096 bayt
• Tuzak: Sanal 4096 → Sayfa 1, Ofset 0 (Sayfa 0 değil!)

3) Tüm Kısaltmalar

CPU (Merkezî İşlem Birimi) • RAM (Ana Bellek) • SSD (Katı Hâl Sürücüsü) • G/Ç (I/O) (Giriş/Çıkış) • API (Uygulama Programlama Arayüzü) • PID (Süreç Kimliği) • PCB (Süreç Kontrol Bloğu) • FCFS (İlk Gelen İlk Hizmet Alır) • SJF (En Kısa İş Önce) • RR (Dönüşümlü Zamanlama) • MMU (Bellek Yönetim Birimi) • KiB (1024 Bayt)
